# Nini

A digital wardrobe and style system — catalogue what you own, build outfits from it, and discover a curated seasonal capsule.

## What this is right now

A single static homepage (`nini.html`) — structure, styling, and design only. No backend, no database, no working buttons yet. This is the starting visual foundation the rest of the app will be built on top of.

## Project structure

```
nini/
├── nini.html      # the homepage — HTML, CSS, and (soon) JS all in one file
└── README.md      # this file
```

## Roadmap

- [x] Homepage design (hero, how it works, seasonal capsule, footer)
- [x] Logo and brand identity
- [ ] Interactivity (JavaScript) — working buttons, forms
- [ ] Wardrobe upload and catalog
- [ ] Outfit builder
- [ ] User accounts (log in / sign up)

## Getting started

Open `nini.html` in any browser to view the site — no build step or install required at this stage.
